# وصلة — مدونة تطبيقات التوصيل 🛵

مدونة عربية متخصصة في عالم تطبيقات التوصيل، **مصممة كأنها تطبيق توصيل**:

| في التطبيق | في وصلة |
|---|---|
| الطلب | المقال (له رقم طلب ووقت توصيل = وقت القراءة) |
| المنيو | التصنيفات: وفّر فلوسك، للمناديب، لأصحاب المطاعم، خلف الكواليس، أدلة |
| تتبّع الطلب | شريط أعلى المقال فيه مندوب يتحرك مع قراءتك حتى «تم التوصيل» |
| تقييم الطلب | تقييم المقال بالنجوم: وصلك ساخن ولا بارد؟ |

## الصفحات
- `index.html` — الرئيسية: تتبع طلب متحرك، المقالات مع بحث وتصنيفات، دليل التطبيقات، النشرة البريدية.
- `article.html?id=...` — صفحة المقال مع متتبع القراءة، جدول المحتويات، التقييم، ومقالات ذات صلة.
- `apps.html` — دليل التطبيقات، جدول مقارنة حسب نوع الخدمة، وقاموس مصطلحات التوصيل.
- `about.html` — فكرة المدونة.

## إضافة مقال جديد
أضف عنصرًا جديدًا إلى مصفوفة `POSTS` في `js/data.js` (المعرّف، التصنيف، الإيموجي، العنوان، الملخص، وقت القراءة، التاريخ، والمحتوى بصيغة HTML). يظهر تلقائيًا في الموقع.

## التشغيل
موقع ثابت بدون أي أدوات بناء:
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
ويمكن نشره مباشرة على GitHub Pages أو Vercel أو Netlify.

يدعم الوضع الليلي، والجوال، واتجاه RTL.
