# أحمد الحربي — الموقع الشخصي

موقع تعريفي بسيط بتصميم تحريري (أبيض وأسود): نبذة، مهارات، أعمال، خبرات، وتواصل.

## تعديل معلوماتك
كل المعلومات في كائن `PROFILE` داخل `js/data.js`. أي نص بين [ ] معلومة مؤقتة لازم تستبدلها.

## الملفات
- `index.html` — الصفحة الرئيسية.
- `css/style.css` — التصميم (يدعم الوضع الليلي والجوال).
- `js/data.js` — معلوماتك.
- `js/main.js` — القائمة، الفوتر، وعرض الأقسام.

## التشغيل والنشر
موقع ثابت بدون أدوات بناء:
```bash
python3 -m http.server 8000
```
وينتشر تلقائيًا على GitHub Pages مع كل تحديث عبر `.github/workflows/pages.yml`.
